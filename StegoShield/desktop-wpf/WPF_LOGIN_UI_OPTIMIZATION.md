## 📞 遇到问题？

### 编译警告
- **CS8618**：可空属性警告 - 不影响功能
- **CS0169**：未使用字段 - 可忽略
- 编译成功，程序可正常运行

### 运行问题
1. **缺少 .NET 8 运行时**：
   - 下载地址：https://dotnet.microsoft.com/download/dotnet/8.0

2. **无法连接服务器**：
   - 确保 Flask 后端正在运行
   - 检查 API 地址配置

3. **界面显示异常**：
   - 尝试切换深色/浅色模式
   - 重启程序
