# StegoShield 桌面应用 - 项目完成报告

## 📋 项目概述

StegoShield 是一款功能强大的图片隐写（Steganography）桌面应用，采用最新的WPF技术和.NET 8.0开发，支持本地离线使用和VIP API服务器模式。

## ✨ 核心功能

### 1. 本地用户认证系统 ✅

**已完成**:
- ✅ 本地用户注册（用户名、邮箱、密码）
- ✅ 本地用户登录（支持离线操作）
- ✅ 密码修改和邮箱更新
- ✅ 用户设置管理
- ✅ AES-256加密存储
- ✅ SHA256密码哈希

**技术实现**:
- 加密存储：`%APPDATA%\StegoShield\users.dat`
- 加密算法：AES-256-CBC
- 密码哈希：SHA256 + Salt

### 2. 图片隐写功能 ✅

**已完成**:
- ✅ LSB隐写算法实现
- ✅ 图片拖放上传
- ✅ 实时预览
- ✅ 批量处理支持
- ✅ 多种图片格式支持（PNG、BMP、JPG）

**功能特性**:
- 隐写（Encode）：将秘密信息隐藏在图片中
- 提取（Decode）：从隐写图片中提取秘密信息
- 质量设置：可调节输出图片质量
- 备份功能：保留原始图片

### 3. VIP会员系统 ✅

**已完成**:
- ✅ VIP状态管理
- ✅ VIP激活/续费
- ✅ VIP专属特权展示
- ✅ VIP到期提醒

**VIP特权**:
- 高级隐写算法（F5、JSteg、OutGuess等）
- 批量处理（最多100张图片）
- 无损压缩
- Reed-Solomon纠错码
- **VIP服务器模式** ✅ 新增
- 无限API调用

### 4. VIP API服务器模式 ✅ **新增**

**已完成**:
- ✅ HTTP REST API服务器
- ✅ API端点认证（X-API-Key）
- ✅ 限流机制（Rate Limiting）
- ✅ API密钥管理（CRUD操作）

**API端点**:

| 端点 | 方法 | 认证 | 描述 |
|------|------|------|------|
| `/api/v1/health` | GET | ❌ | 健康检查 |
| `/api/v1/stego/encode` | POST | ✅ | 图片隐写 |
| `/api/v1/stego/decode` | POST | ✅ | 提取数据 |
| `/api/v1/vip/status` | GET | ✅ | VIP状态 |
| `/api/v1/keys` | GET | ✅ | 密钥列表 |
| `/api/v1/keys` | POST | ✅ | 创建密钥 |
| `/api/v1/keys/{id}` | DELETE | ✅ | 删除密钥 |

**技术特性**:
- 基于HttpListener的轻量级服务器
- JSON格式请求/响应
- CORS支持（跨域访问）
- 自动限流（每小时100请求）
- 多端口支持（默认5001）

### 5. 现代化UI设计 ✅

**已完成**:

- ✅ 现代化卡片设计
- ✅ 平滑动画效果

**页面结构**:

## 📝 使用文档

### 快速开始

1. **安装和运行**
   ```
   下载最新版本
   解压到任意目录
   运行 StegoShield.Desktop.exe
   ```

2. **创建账户**
   ```
   点击"注册账户"
   填写用户名、邮箱、密码
   点击"注册"
   ```

3. **激活VIP（可选）**
   ```
   点击"升级到VIP"
   确认激活
   ```

4. **使用隐写功能**
   ```
   选择"图片隐写"
   拖放图片到窗口
   输入要隐藏的文字
   点击"开始隐写"
   ```

5. **启动API服务器（VIP）**
   ```
   选择"VIP中心"
   点击"启动服务器"
   复制API密钥
   ```

```csharp
public async Task TestUserRegistration()
{
    var result = await UserService.Instance.RegisterAsync("testuser", "test@example.com", "password123");
    Assert.IsTrue(result.Success);
}
```

**集成测试**:
```csharp
[TestMethod]
public async Task TestStegoEncodeDecode()
{
    var imagePath = "test_image.png";
    var text = "Secret Message";
    
    var encodeResult = await StegoService.Instance.EncodeAsync(imagePath, text);
    Assert.IsTrue(encodeResult.Success);
    
    var decodeResult = await StegoService.Instance.DecodeAsync(encodeResult.OutputPath!);
    Assert.AreEqual(text, decodeResult.ExtractedText);
}
```
