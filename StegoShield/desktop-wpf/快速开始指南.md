# 🚀 StegoShield 快速开始指南

## 快速启动

### 1. 运行应用

```
找到编译输出目录:
C:\Users\17544\.openclaw\workspace\main\StegoShield\desktop-wpf\StegoShield.Desktop\bin\Debug\net8.0-windows\win-x64\

运行:
StegoShield.Desktop.exe
```

### 2. 首次使用

#### 步骤1: 注册账户

1. 点击"注册账户"按钮
2. 填写信息:
   - 用户名: `admin`
   - 邮箱: `admin@example.com`
   - 密码: `password123`
3. 点击"注册"
4. 注册成功后自动登录

#### 步骤2: 激活VIP

1. 在主界面点击"VIP中心"（皇冠图标）
2. 点击"升级到VIP"按钮
3. 确认激活
4. VIP有效期为1年

#### 步骤3: 启动API服务器

1. 在VIP中心页面
2. 找到"API服务器控制"区域
3. 点击"启动服务器"按钮
4. 服务器将在 http://localhost:5001/ 启动

#### 步骤4: 创建API密钥

1. 在"API密钥管理"区域
2. 点击"+ 生成新密钥"按钮
3. 复制API密钥（只会显示一次！）
4. 保存到安全的地方

### 3. 使用图片隐写

#### 隐写数据

1. 点击"图片隐写"（笔图标）
2. 拖放一张PNG或BMP图片到窗口
3. 在文本框中输入要隐藏的信息
4. 点击"开始隐写"按钮
5. 选择保存位置
6. 完成！

#### 提取数据

1. 点击"数据提取"（放大镜图标）
2. 拖放隐写后的图片
3. 点击"提取数据"按钮
4. 隐藏的信息将显示在界面上

### 4. 使用API服务器

#### 测试API

使用PowerShell测试API：

```powershell
# 1. 健康检查（不需要API密钥）
Invoke-RestMethod -Uri "http://localhost:5001/api/v1/health" -Method Get

# 2. 获取VIP状态（需要API密钥）
Invoke-RestMethod -Uri "http://localhost:5001/api/v1/vip/status" `
    -Headers @{ "X-API-Key" = "your_api_key_here" }

# 3. 隐写图片（需要API密钥）
$body = @{
    ImagePath = "C:\test\image.png"
    Text = "要隐藏的信息"
    Algorithm = "LSB"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:5001/api/v1/stego/encode" `
    -Method Post `
    -ContentType "application/json" `
    -Headers @{ "X-API-Key" = "your_api_key_here" } `
    -Body $body

# 4. 提取数据（需要API密钥）
$body = @{
    ImagePath = "C:\test\output.png"
    Algorithm = "LSB"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:5001/api/v1/stego/decode" `
    -Method Post `
    -ContentType "application/json" `
    -Headers @{ "X-API-Key" = "your_api_key_here" } `
    -Body $body
```

使用curl测试：

```bash
# 健康检查
curl http://localhost:5001/api/v1/health

# 隐写图片
curl -X POST http://localhost:5001/api/v1/stego/encode \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your_api_key_here" \
  -d '{"ImagePath": "C:\\test\\image.png", "Text": "Hello World", "Algorithm": "LSB"}'

# 提取数据
curl -X POST http://localhost:5001/api/v1/stego/decode \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your_api_key_here" \
  -d '{"ImagePath": "C:\\test\\output.png", "Algorithm": "LSB"}'
```

## 🔧 故障排除

### 问题1: 应用无法启动

**解决方案**:
1. 检查.NET 8.0 Runtime是否安装
2. 重新编译项目: `dotnet build`
3. 检查防病毒软件是否阻止

### 问题2: API服务器无法启动

**解决方案**:
1. 检查5001端口是否被占用: `netstat -ano | findstr 5001`
2. 使用管理员权限运行应用
3. 检查防火墙设置

### 问题3: 隐写失败

**解决方案**:
1. 确保使用PNG或BMP格式图片
2. 检查图片大小是否足够隐藏数据
3. 确保有写入权限

### 问题4: 无法提取数据

**解决方案**:
1. 确认图片是使用LSB算法隐写的
2. 检查图片是否被压缩或转换过
3. 尝试不同的算法

## 🎯 快速参考

### 常用操作

| 操作 | 路径 | 说明 |
|------|------|------|
| 注册 | 登录页面 | 首次使用需要注册 |

```

```

