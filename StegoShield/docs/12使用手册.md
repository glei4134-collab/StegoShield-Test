## 12.4 功能演示

### 演示一：文字隐写

#### 步骤
1. 选择"嵌入数据"标签
2. 上传一张PNG图片
3. 选择隐写方法（推荐LSB）
4. 在文本框输入要隐藏的内容
5. （可选）启用加密
6. （可选）启用抗压缩
7. 点击"开始嵌入"
8. 下载结果图片

#### 提取步骤
1. 选择"提取数据"标签
2. 上传包含隐写数据的图片
3. （如需解密）输入密钥
4. 点击"开始提取"
5. 查看提取的内容

## 12.5 API 调用示例

### Python 示例
```python
import requests
import base64

# 嵌入API
def embed_message(image_path, message):
    with open(image_path, 'rb') as f:
        image_b64 = base64.b64encode(f.read()).decode()
    
    response = requests.post('http://127.0.0.1:5001/api/embed', json={
        'image': image_b64,
        'type': 'text',
        'content': {'text': message},
        'method': 'lsb',
        'compressResistant': True,
        'encryption': {'enabled': False}
    })
    
    result = response.json()
    if result['success']:
        return result['data']['image']
    return None

# 提取API
def extract_message(image_path):
    with open(image_path, 'rb') as f:
        image_b64 = base64.b64encode(f.read()).decode()
    
    response = requests.post('http://127.0.0.1:5001/api/extract', json={
        'image': image_b64,
        'decryption': {'enabled': False}
    })
    
    result = response.json()
    if result['success']:
        return result['data'].get('text')
    return None
```

### cURL 示例
```bash
# 嵌入
curl -X POST http://127.0.0.1:5001/api/embed \
  -H "Content-Type: application/json" \
  -d '{
    "image": "图片base64",
    "type": "text",
    "content": {"text": "隐藏消息"},
    "method": "lsb",
    "compressResistant": true
  }'

# 提取
curl -X POST http://127.0.0.1:5001/api/extract \
  -H "Content-Type: application/json" \
  -d '{
    "image": "图片base64",
    "decryption": {"enabled": false}
  }'
```

## 12.6 常见问题

### Q1: 嵌入失败怎么办？
**A**: 检查以下问题：
- 图片是否太小？（建议至少512×512）
- 内容是否超过图片容量？
- 图片格式是否支持？（推荐PNG）

### Q2: 提取失败怎么办？
**A**: 检查以下问题：
- 图片是否经过压缩？（关闭抗压缩后压缩会导致失败）
- 加密密钥是否正确？
- 图片是否被修改过？

### Q3: 抗压缩和加密可以同时使用吗？
**A**: 可以！加密和抗压缩是独立功能，可以同时启用。

### Q4: 支持哪些图片格式？
**A**: 
- LSB方法：PNG、BMP、TIFF（推荐PNG）
- DCT方法：JPEG

### Q5: 最大支持多大的图片？
**A**: 当前配置支持最大5000×5000（约70MB）的图片。
