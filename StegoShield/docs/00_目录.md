## 项目核心亮点

| 维度 | 内容 |
|------|------|
| 创新性 | 双算法隐写 + AES加密 + 抗压缩 |
| 技术性 | Python + Flask + 图像处理 |
| 实用性 | 支持文件嵌入、加密保护 |
| 性能 | 支持5000×5000大图、150+次抗压缩 |

---

## 技术架构

```
前端: HTML5 + CSS3 + JavaScript
后端: Flask + Python
算法: LSB + DCT 隐写
加密: AES-256-GCM
```

---

## 功能清单

- [x] LSB 隐写（PNG/BMP）
- [x] DCT 隐写（JPEG）
- [x] AES-256 加密
- [x] 抗压缩（150+次）
- [x] 文件嵌入
- [x] RESTful API
